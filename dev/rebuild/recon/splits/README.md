# Split hunts — status after Heisen's answers

*Author: Aaron (+ Claude session) · 2026-10-31*

*Class: LIVING. The split docs are ARCHIVE, so this table records what each finding is now worth to the spec. The
reasons are in [`../questions-for-list-authors.md`](../questions-for-list-authors.md) (answers and dispositions) and
`../../decisions.md` (2026-10-31: reference stance, NPC doctrine, design rule).*

**Reading rule:** values come from Requiem and its addons, with each addon winning in its own area. A split rule
survives when it *is* that rule applied, or when it is a house convention Heisen confirmed. Residuals and
exceptions are not taught.
