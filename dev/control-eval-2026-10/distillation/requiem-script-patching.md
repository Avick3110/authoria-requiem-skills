It covers: deciding whether a record needs a script; cloning Magic Redone's `Nox_*` VMAD onto new special-mechanic spells; registering a modded follower with `REQ_FollowerRegistration`; and compiling a new `.psc`. It has 793 lines: SKILL.md 269, follower-registration.md 126, housecarl-recipes.md 136, nox-runtime-map.md 106, vmad-and-compile.md 78, req-core-scripts.md 51, index.jsonl 27.
- **How often it was used.**
  - Loaded in **3 of 21 skill runs, all in FS**: s1 (lane sub:5), s1n and s2 (U8 L12, L56).
  - SKILL.md was read 3 times and follower-registration.md 2 times. **The other 4 references were never opened** (U8 L157-162; FS s1 mining `sections_read_not_acted_on`).
  - **0 of 151 rules have a recorded use.** It is the only skill with zero evidence (U8 L12, L53).
  - It was never loaded in AC (222 scripted QUST), FQ (vanilla Favor QUST overrides with scripts), MC, RB or TR (U8 L29; U7 L28, L40). In FQ the router's VMAD row pointed here (rp#14). Skill runs s1 and s2 read the row and did not load the skill; s3 never looked at the VMAD (ledger FQ L44-45, L66).
  - None of the 17 deciding points in U7/R2 involves this skill. In R2, FQ is "no skill text behind any right call" (R2 favor-quests L12).

## 6. Rewrite brief

**Recommendation: retire it as a standalone skill.** Split its useful ~10% across the layers below. If a script skill is kept, it is a **~60-80 line Requiem-profile reference called "scripts and VMAD"**, rebuilt around *existing* scripts (bind, preserve, inherit), not around *attaching new* ones.

- **Purpose (new).** Every script-carrying record in a patch must end up bound and working under the live load order. That covers: the mod's own scripts; clones of vanilla records; scripts the build attaches; and, rarely, a new special mechanic.
- **Must keep (verbatim facts or probes).**
  1. The probes: `housecarl_records where=["VirtualMachineAdapter exists"]` (every type in one query) and `housecarl_check findings=["scripts","unbound"]` → **general layer** ("dissect the mod fully, scripts included").
  2. "Preserve the mod's script properties; never drop one" (F4) → general layer.
  3. REQ_NULL in a property: PERK → replace or drop; any other type → keep (F2) → **Requiem profile, invariants**.
  4. Special mechanic → clone the MR comparable's VMAD by script name; each sibling gets its own fills; arrays at the right size; shared Requiem forms (MysticInfusion, XarrianCell, CharmFaction) stay → **Requiem profile, analogue keys** (mark untested).
  5. Never edit a REQ_* control script; register with it → Requiem profile (1 line).
- **New items.**
  - **N1 (the gap; FQ's deciding fix).** "Clone-of-vanilla trap: a mod's copy of a vanilla record does not inherit Requiem's or the live stack's edits. Diff the vanilla original's live winner (VMAD included) into each clone. Bind each property to the type the **winning** `.pex` declares. If the `.pex` is in a BSA: `housecarl_bsa_extract` + `housecarl_decompile_script`. Probe: `housecarl_check findings=unbound` = 0 after the write." → **Requiem profile, traps** (the clone half also applies to non-script fields; route the router's triage to it).
  - **N2.** REQ_LockpickControl as an upstream/downstream line (F1) → **Requiem profile, generator contract**, in the downstream package list next to the RFTI NPC chassis and the weapon bake.
  - **N3.** Router change: the VMAD/QUST row must point at N1, not at "most patches need none" (rp#169). A liveness check (reverse references) comes before any LVLI/VMAD route (FQ s3).
- **Delete.** housecarl-recipes.md, vmad-and-compile.md, the freshness probe, the bulk-pass prose, the Judgment / Common mistakes / Checklist / Notes restatements, the staff-keyword lines (the weapon skill owns them), the "plain spell needs no script" gate (1 line in the profile instead), index.jsonl and evals from the shipped copy. Total ~650 of 793 lines.
- **Move.**
  - Follower registration → **ARR list layer** (~10 lines, default instead of an ask; standalone quest; never extend the Authoria bridge; verify the bridge ESP is active by probe).
  - VMAD write shapes, compile, `.seq` → **houseCARL** skills.
  - The upstream/downstream statement → Requiem profile, once.
- **Target length.** ~60-80 lines in total, spread over the layers. 0 lines left as its own SKILL.md.
- **Retest.** A new task with an existing script fault (an unbound or mistyped property on cloned quests, or a dropped mod property). FQ is the only task in this eval that had one, and the controls already solved it 4/4. So the measure is cost and consistency (s3's miss), not correctness.
